Boat calibration

← Back to the dashboard · Readings update every second and are smoothed, so let a number settle for a few seconds before you save it. Nothing here changes what the boat does; it only teaches the dashboard what your senders mean.

The sensors are simulated (BOAT_SENSORS is not n2k or real), so there's no real sender to calibrate against -- these are just the numbers the simulator is currently making up, so you can see the page and the layout ahead of wiring anything up.

NMEA 2000

Your engine converter (for example the CX5003) should appear above with its RPM, trim, oil pressure and temperature. If nothing shows, check that the CAN interface is up (BOAT_CAN=can0), the converter has power, and the backbone has a terminator at each end. If a value is heard under an instance number other than the one in use, set BOAT_N2K_ENGINE_INSTANCE (RPM, trim, oil, temperature) or BOAT_N2K_FUEL_TANK_INSTANCE (fuel level) to match. If the temperature arrives as an oil temperature rather than an engine temperature, set BOAT_N2K_TEMP=oil.

A fuel-flow sensor sends fuel rate (used for GPH and MPG). A tank-level adapter sends the tank level (used for the fuel gauge, ahead of any analog sender). If your device shows up here with a different instance number than the settings expect, set BOAT_N2K_ENGINE_INSTANCE (flow sensor) or BOAT_N2K_FUEL_TANK_INSTANCE (tank level) to match.

A depth transducer shows up here too (and its sea temperature, if it sends one). With more than one on the bus, the freshest is used; to pick one, set BOAT_N2K_DEPTH_SOURCE to its device number.

Depth

--ft shown

The transducer's own offset (to the waterline, or to the keel if it was installed that way) is already included above. Type the true depth (from a lead line, a marked dock piling, or a known chart depth at your slip) to add a further correction on top of that.

Fuel level

--% from the converter --% shown

For a US-standard 240-33 ohm sender, connect the converter's "switch" wire to ground. The level is used as it arrives; if the tank never quite reads 0% or 100%, save the reading when it is truly empty and when it is truly full.

Trim

--% from the converter --% shown

The converter reads trim senders over 0-190 ohms; measure yours with a multimeter first, because anything above 190 ohms would be cut off. Run the drive fully DOWN (in) and save, then fully UP (out) and save. Trim shows "--" until both are saved.

Oil pressure

--psi as the converter reports it --psi shown

Converters like the CX5003 assume a 10 bar (145 psi) sender. A US-standard sender is 80 psi full scale, so the converter reads it about 1.8 times too high. Type your sender's full-scale psi to correct it (80 for US-standard; 145 leaves the reading as reported). Check it against a mechanical gauge if you can.

Gauge power

--V at the gauges

The analog gauges stay connected and keep working; the board only reads the wires they already drive. Every reading is taken relative to the gauges' own supply, so it doesn't shift when the engine starts charging. The key must be ON (engine can be off) to save anything, because the gauges are dark otherwise.

Check once: with the key on, note the fuel % shown, then start the engine. It should not move. If it moves by more than a percent or two, your gauges regulate their own supply: switch to plain volts (this clears saved points).

Fuel level

--% shown --V on the sender wire

Two points calibrate the whole gauge, empty included. The best first one is real: right after filling up. Then, any time later, tap the mark the analog gauge is pointing at. Points far apart work best; a new point at the same level replaces the old one.

Trim

--% --V on the sender wire

Run the drive fully DOWN and save, then fully UP and save. If the dashboard and the analog gauge disagree in the middle, set the drive so the analog gauge is at its middle mark and save that too.

Oil pressure

--psi --V on the sender wire

Key ON with the engine off is 0 psi: save that. Then with the engine running, save what the analog gauge reads -- at idle and again at cruise gives the best in-between.

Engine temperature

--F --V on the sender wire

Two points calibrate the whole gauge, overheat included. First with the engine cold: key ON after it has sat a few hours, and type the air or lake temperature -- that's what the engine is at. Then warmed up: type what the analog gauge reads, or better, an infrared thermometer aimed at the thermostat housing. A third point anywhere in between tightens it further.

Fuel level (analog sender)

--ohms --% shown

US-standard senders read about 240 ohms empty and 33 ohms full. To calibrate, capture the reading when the tank is truly empty and when it is truly full. If a NMEA 2000 tank-level adapter is present it takes priority over this.

Trim

--ohms --%

Alpha One trim senders are resistive but the range varies, so measure yours: run the drive fully DOWN (in) and save, then fully UP (out) and save. Trim shows "--" until both are saved.

Oil pressure

--ohms --psi

US-standard 0-80 psi senders read about 10 ohms at 0 psi and 180 ohms at 80 psi. With the engine off (0 psi) you can save the zero point.

Battery voltage

--volts (raw --)

With BOAT_BATTERY_ADC=true the Pi measures the battery on an ADS1115; otherwise it uses the converter's alternator volts if the converter sends them. Measure the battery with a multimeter and type what it shows to calibrate the ADS1115 reading.

Measure the battery with a multimeter and type what it shows.

House battery

--volts (raw --)

The sensor board's HSE+ input (J1.8, BOAT_HOUSE_BATTERY=true). Measure the house battery with a multimeter and type what it shows.

Tach (RPM)

--rpm (raw --)

With the engine running steadily, type what the ANALOG tach shows. The converter's speed-ratio DIP switches must already be right (ratio 2 for a 4-cylinder, 4-stroke gasoline engine); this scale only corrects small errors, so if the two differ by a factor of two, fix the switches instead.

With the engine running steadily, type what the ANALOG tach shows. For a 4-cylinder distributor engine the raw value should already be close (set BOAT_TACH_PPR=2).

Temperature probes

Engine (coolant) temperature comes from the converter's temperature input, so a probe here is optional: use one on the raw-water intake hose for the water temperature (assign it to Water). A probe you assign to Engine is used only when the converter sends no temperature.

Warm one probe in your hand to see which is which, then assign it. If you have one probe it is used as the engine (coolant) probe automatically. A probe clamped to the thermostat housing reads a little below true coolant temperature; to correct that, type a true temperature (for example from an infrared thermometer aimed at the housing).

Fuel burn (GPH)

--gallons counted since the last fill-up

The count comes from the NMEA 2000 fuel-flow sensor if there is one, otherwise from an estimate based on RPM. At each fill-up, top the tank off and type the gallons the pump put in; the fuel burn rescales to match reality. It gets more accurate every time.
