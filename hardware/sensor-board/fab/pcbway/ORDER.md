# Ordering the sensor board from PCBWay

Board rev 1.1: 65 × 76 mm, 2 layers. Everything here is generated by `build.py`; rebuild before
ordering if the design has changed since.

## Checked before ordering

- **KiCad's checks**: the electrical rules check (ERC), the design rules check (DRC) and the
  schematic-to-board parity check report nothing at any severity. PCBWay's own limits are
  written into the design rules, so DRC enforces them: 0.1 mm tracks and gaps (this board uses
  0.2), a 0.15 mm annular ring (vias here have 0.2), 16 mil between holes, 0.25 mm copper to a
  routed edge (0.3 here), silkscreen 0.8 mm tall with a 0.15 mm stroke.
- **Pinouts read from the manufacturers' datasheets**, not assumed from KiCad's library:
  ISO1044 (TI), MCP2518FD (Microchip, Table 1-1), uA78L05 in SOT-89 (TI: 1 out, 2 ground,
  3 in), NUP2105L (onsemi), EL817 (Everlight, including its surface-mount land pattern against
  the footprint), the Abracon ASE oscillator (pin 1 enable tied high = running).
- **Part numbers** in the BOM are all real, orderable parts; the Phoenix Contact numbers were
  looked up one by one.

## The bare board: pcbway.com → PCB Instant Quote → Quick-order PCB

Upload the Gerber zip; PCBWay reads the size and layers from it. Then:

| Option | Choose |
| --- | --- |
| Board type | Single pieces |
| Size | 65 × 76 mm (from the Gerbers) |
| Quantity | 5 (PCBWay's minimum; spares are handy) |
| Layers | 2 |
| Material | FR-4, TG130-140 |
| Thickness | 1.6 mm |
| Min track / spacing | 6/6 mil (the board's smallest is 8/8) |
| Min hole size | 0.3 mm |
| Solder mask / silkscreen | Green / White |
| Edge connector | No |
| Surface finish | HASL lead free (or Immersion gold, ENIG, for flatter pads under the 0.5 mm-pitch ADCs -- worth it if PCBWay assembles) |
| Via process | Tenting vias |
| Finished copper | 1 oz |
| Remove product No. | Your choice: PCBWay prints an order number on the silkscreen unless told otherwise |

If you're assembling by hand, add a **stencil** (framework: none) -- it makes the fine-pitch
parts far easier.

## Assembled by PCBWay: pcbway.com → PCB Assembly

| Option | Choose |
| --- | --- |
| Service | Turnkey (PCBWay buys the parts) |
| Quantity | 1-5 |
| Assembly sides | Top side (every SMD part is on top; J4 goes on the bottom but is through-hole, soldered from the top) |
| Unique parts | 30 lines in the BOM |
| SMD pads | 174 |
| Through-hole pins | 58 (J1-J5) |
| Board | the same settings as above, ENIG finish |

In the notes: *"Assemble all SMD parts. Through-hole J1, J2, J3, J5 and J4: [assemble / do not
fit -- customer will solder]. JP1 is a solder jumper: leave it OPEN."*

Soldering the five through-hole connectors yourself is easy and saves the through-hole charge;
J4 in particular (the 2×20 stacking header, Adafruit 1979) may be easier to buy yourself.

PCBWay's engineers review every order and may email about substitutions -- the likely ones are
Y1 (any 40 MHz 3.3 V CMOS oscillator in the 3.2 × 2.5 mm ASE footprint is fine) and U3 (any
PC817-type gull-wing optocoupler, CTR rank C or B).
